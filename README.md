# Kyro Zhao · Personal Portfolio

Berklee College of Music · Music Business — scrapbook / new-ugly portfolio site.

## Stack

- Vite + React + TypeScript
- Static export for GitHub Pages (`npm run build` → `dist/`)

## Local

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Deploy

Push to `main` triggers `.github/workflows/deploy.yml` (GitHub Pages via Actions).
In the repo: **Settings → Pages → Source: GitHub Actions**.
